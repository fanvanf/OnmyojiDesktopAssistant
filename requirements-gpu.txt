# GPU variant requirements
# This requirements file swaps the CPU `onnxruntime` for `onnxruntime-gpu`.
#
# WARNING: `onnxruntime` and `onnxruntime-gpu` ship the same files and cannot
# coexist in one environment. Uninstall `onnxruntime` BEFORE installing the GPU
# package, otherwise pip leaves a mixed/corrupted installation:
#  - Uninstall CPU onnxruntime:
#      pip uninstall -y onnxruntime
#      # or if installed via uv
#      uv pip uninstall -y onnxruntime
#  - Install packages using pip:
#      pip install -r requirements-gpu.txt
#  - Or using uv:
#      uv pip install -r requirements-gpu.txt
#
# The `onnxruntime-gpu` version must match your CUDA/cuDNN version.
# See https://onnxruntime.ai/docs/execution-providers/CUDA-ExecutionProvider.html
#
# After installing, GPU inference is enabled in `src/utils/rapidocr.py` by
# setting `EngineConfig.onnxruntime.use_cuda` to True.
